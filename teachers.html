Classroom use

Use this when the panic is “just write it for them.”

Students already have chatbots. Banning the URL does not ban the skill gap. This site gives them a script: decode the assignment, try first, ask for tutoring, disclose.

Sample syllabus line

Generative AI may be used as a tutor: to explain ideas, quiz you, and comment on work you already produced. It may not produce the speech, paper, code, lab report, or answers you submit. If you use a tutor, add a two-sentence disclosure. Submitting unedited or lightly edited model text is a integrity violation. When unsure, ask me before you paste.

15-minute activity

  1. 3 min. Students open Assignment studio, pick the real type (Speech or Research paper if you want a common demo).
  2. 4 min. They paste your actual prompt — or the school-start-times / urban-heat example — and generate a plan.
  3. 4 min. Pair-share: one GREEN prompt they will use; one RED prompt they will not.
  4. 4 min. Prompt gym: classify two items. Exit ticket: “Generative AI predicts likely text; it does not understand like a person.”

What you can expect to see

Rule-based plans, not a hidden homework mill. Tutor mode refuses RED asks. Last plan stores in the browser only unless you later add a server — we did not.

If you want process points, collect the disclosure plus a photo of the handwritten try-first list. Grade the thinking you asked for.
